## Описание

Приложение на Node.js для анализа содержимого каталога.

Программа рекурсивно обходит указанный каталог и определяет:
- количество файлов;
- количество вложенных каталогов;
- суммарный размер файлов в байтах.

Результат выводится в формате:

`336095-ФАЙЛЫ-КАТАЛОГИ-БАЙТЫ`

## Технологии

- JavaScript (Node.js)
- Docker

## Сборка Docker-образа

```bash
docker build -t lab1-component .
```

## Запуск

```bash
docker run --rm -v "C:\lab1-component\test-data:/data:ro" lab1-component /data
```

## Пример результата

```text
336095-3-1-20
```
